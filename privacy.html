Privacy Policy

Updated: October 28, 2026 · PlaylistBridge Windows desktop application

This Privacy Policy explains how PlaylistBridge processes information when you connect your Spotify or YouTube account and transfer playlist entries. PlaylistBridge is an independent Windows desktop utility and is not affiliated with Spotify, Google or YouTube.

1. Application purpose

PlaylistBridge transfers playlist entries and identifiers between accounts that you authorize. It reads playlists, finds candidate media matches, and creates or updates destination playlists when you request it. It does not download, copy or transfer the underlying music or video files.

2. Data accessed

When you use relevant features, the application may access or process:

  • Spotify playlist and saved/top-track metadata: song titles, artists, album names, track and playlist IDs, and related account playlist information.
  • YouTube API data: authorized channel name and ID, playlist/video identifiers and titles, playlist entries, video search results, and candidate matches.
  • OAuth access and refresh tokens, local application settings, source/destination associations, transfer progress, and diagnostic error logs. Logs may contain playlist titles and IDs.

PlaylistBridge requests the Google OAuth scope https://www.googleapis.com/auth/youtube.force-ssl to read and manage the user's YouTube playlists and entries, including creation, editing and deletion following explicit user actions. Song titles and artist names are submitted in YouTube search requests to locate matches. The application also requests Spotify OAuth scopes needed for its selected playlist features.

3. Processing and local storage

PlaylistBridge communicates directly with the Spotify, Google OAuth and YouTube APIs. Application settings, OAuth tokens, transfer state, search matches and local mappings are stored in the user's Windows application data directory (%LOCALAPPDATA%\PlaylistBridge), rather than in a publisher-hosted music-library database. Stored tokens and protected credentials use Windows Data Protection API (DPAPI) for the current Windows user. The app does not collect Google or Spotify passwords.

There is no publisher-operated account registration system, advertising functionality, or independent behavior-tracking/analytics service in the Windows application. User data obtained through the YouTube API is not sold to advertisers or data brokers.

4. Retention

Individual local search/match-cache records expire after 30 days. At startup, the application removes transfer session, search and certain other snapshot files older than 30 days. Other locally stored destination associations or index records may remain during ongoing use, including where a shared file is rewritten, to avoid duplicate playlist creation and support transfer recovery. Such retained local YouTube-related data is removed when YouTube is disconnected or when the relevant local application data is deleted. OAuth tokens are kept while authorization remains needed and valid.

5. Disconnecting, revocation and deletion

Select Disconnect YouTube in PlaylistBridge to request revocation of the saved Google OAuth token through Google's official endpoint. On successful revocation or confirmation that the token is already invalid, PlaylistBridge deletes the locally stored YouTube token and associated YouTube data, session state, search/match caches, transfer mappings and diagnostic logs. The Spotify authorization and general preferences are retained. Interrupted local cleanup is retried at startup.

If Google cannot be reached, PlaylistBridge cannot confirm remote revocation. The user may select local-only removal and should also revoke the app's access manually in Google Account third-party connections. Spotify permissions may be revoked from Spotify account app settings.

Deleting local PlaylistBridge data or disconnecting an account does not delete remote playlists, songs or videos. Manage or delete such content directly in the respective service.

6. Third-party services and terms

PlaylistBridge uses YouTube API Services. By using the YouTube features of PlaylistBridge, users also agree to the YouTube Terms of Service. Learn about Google's handling of data in the Google Privacy Policy. Spotify API interactions are subject to Spotify's applicable terms and policies.

7. Security

OAuth sign-in occurs through each service's official webpages in the system browser. PlaylistBridge does not ask for account passwords. Tokens and eligible credentials saved locally are protected using Windows DPAPI. No storage or communication method is completely risk-free.

8. Policy updates

This page may be updated to reflect changes in PlaylistBridge functionality, permissions, or API usage. The updated date above will be revised when material changes are published.
