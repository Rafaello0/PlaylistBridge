Privacy Policy

Effective date: October 9, 2026

This Privacy Policy explains how PlaylistBridge handles information when you use the PlaylistBridge Windows desktop application.

1. Overview

PlaylistBridge is a personal desktop utility for transferring music playlists and library items between Spotify and YouTube. The application is designed to process data locally on the user's computer except when it sends requests directly to Spotify and Google/YouTube APIs as required to perform a user-requested transfer.

2. Information processed

Depending on the features you use, PlaylistBridge may process:

  • Spotify playlist metadata, saved-track metadata, top-track metadata, track identifiers, artist names, album names, and playlist identifiers.
  • YouTube playlist metadata, video identifiers, video titles, channel information, and search results needed to match music.
  • OAuth access and refresh tokens needed to access the accounts that you explicitly connect.
  • Application settings, transfer progress, match scores, and locally cached Spotify↔YouTube matches.

3. How information is used

Information is used only to provide the application functions requested by the user, including reading source playlists/library items, searching for corresponding media, creating or updating destination playlists, avoiding duplicate work, and resuming interrupted transfers.

4. Local storage

Application settings, OAuth tokens, transfer state, and the match cache are stored on the user's Windows computer under the PlaylistBridge application data directory. OAuth tokens and protected credentials are stored using Windows data protection mechanisms. PlaylistBridge does not operate a separate backend database for collecting user music-library data.

5. YouTube API Services and Google data

PlaylistBridge uses YouTube API Services. By using YouTube-related features, you also agree to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

PlaylistBridge requests Google/YouTube OAuth authorization only for functionality needed to read and manage the user's YouTube playlists and related YouTube resources used by the transfer workflow. Google user data obtained through the YouTube API is not sold, used for advertising, or transferred to data brokers.

6. Spotify data

Spotify authorization is performed using Spotify OAuth. PlaylistBridge requests permissions needed to read authorized playlists/library data, read top tracks for optional filtering, and create or modify playlists at the user's request.

7. Sharing of information

PlaylistBridge does not sell personal information. The application sends information to Spotify and Google/YouTube only as necessary to use their APIs and to perform actions requested by the user. No independent analytics or advertising service is built into PlaylistBridge.

8. Retention and deletion

Local application data remains on the user's computer until it is removed. A user may disconnect an account to remove the corresponding stored OAuth token. To remove all PlaylistBridge local data, the user may delete the PlaylistBridge application data directory from their Windows profile. Access granted to Google can also be revoked from the user's Google Account security/third-party access settings, and Spotify access can be revoked from Spotify account application settings.

9. Security

PlaylistBridge uses OAuth authorization in the user's system browser and does not collect Spotify or Google account passwords. Protected local credentials are stored using Windows data protection facilities. No method of software or data storage can provide an absolute security guarantee.

10. Changes

This Privacy Policy may be updated when PlaylistBridge features, permissions, or API usage change. The effective date at the top of this page will be updated when material changes are made.
