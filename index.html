Personal desktop utility

Move playlists between Spotify and YouTube.

PlaylistBridge is a local Windows application that helps a user migrate their own music library between Spotify and YouTube, review uncertain matches, reuse cached matches, and resume transfers without starting over.

Windows desktopSpotify OAuthGoogle OAuthYouTube Data API v3Local cache
PlaylistBridge does not ask for Spotify or Google passwords. Authentication is performed on the official provider websites using OAuth.

What PlaylistBridge does

Spotify → YouTube

Reads an authorized Spotify playlist or the user's saved tracks, finds corresponding YouTube videos, and creates or updates a YouTube playlist.

YouTube → Spotify

Reads an authorized YouTube playlist, finds corresponding Spotify tracks, and creates or updates a Spotify playlist.

Local matching cache

Stores successful track matches locally so previously matched music does not need to be searched again on later runs.

Data use and API access

PlaylistBridge is designed as a local desktop application. OAuth tokens, settings, transfer session state, and the match cache are stored on the user's Windows computer. OAuth tokens and protected credentials are stored using Windows data protection mechanisms.

The application communicates directly with Spotify and Google/YouTube APIs to perform the actions requested by the user. PlaylistBridge does not operate a separate backend service for collecting user library data, does not sell user data, and does not use user data for advertising.

PlaylistBridge uses YouTube API Services. Use of YouTube features is subject to the YouTube Terms of Service and Google's Privacy Policy.
