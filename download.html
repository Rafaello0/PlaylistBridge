1. Install and start

  1. Download the review ZIP after its public link is provided.
  2. Extract the ZIP to a folder on a Windows 10 or 11 x64 computer.
  3. Run PlaylistBridge.exe from the extracted folder.
  4. Ensure internet access is available, then connect the accounts needed for your test.

No separate .NET runtime installation is required for this self-contained build. If Windows displays an unknown-publisher or security warning, check the publisher, download source and SHA-256 before proceeding; do not bypass organizational security policies.

2. Connect accounts

Google / YouTube

Select Connect YouTube in PlaylistBridge. The application opens Google's official OAuth sign-in page in your system browser. Sign in using a reviewer-controlled Google account, review the permissions and continue.

PlaylistBridge requests https://www.googleapis.com/auth/youtube.force-ssl to read and manage authorized YouTube playlists. Depending on the Google project's verification or testing state, access may need to be arranged with the developer.

Spotify — Development Mode

Spotify restricts access to explicitly authorized users while the Spotify application is in Development Mode. Reviewers who want to use their own Spotify account must first request allowlist access from the developer.

Do not send passwords or OAuth tokens. Spotify sign-in is performed on Spotify's official OAuth page. Please contact the developer with the Spotify account identifier needed for allowlisting.

3. Suggested review scenario

  1. Start PlaylistBridge and connect Google / YouTube using OAuth.
  2. Arrange Spotify allowlist access if necessary, then connect Spotify.
  3. Select an authorized Spotify playlist or saved tracks.
  4. Search for YouTube matches and review uncertain candidates.
  5. Choose an existing YouTube destination playlist or create a new one.
  6. Start the transfer, then open YouTube to verify the playlist entries.
  7. Review the account-disconnect options and the privacy and terms documents.

PlaylistBridge transfers playlist metadata and entries, not audio/video files. API actions are performed by the Windows application on behalf of the signed-in user.

Verify the extracted executable using Windows PowerShell:

Get-FileHash -Algorithm SHA256 .\PlaylistBridge.exe

The released executable must match the value above. A separate SHA-256 for the published ZIP should also be provided when the final package is uploaded.

5. Privacy and support

Tokens and configuration are stored locally on the user's Windows computer; protected credentials use Windows DPAPI. PlaylistBridge does not ask for Spotify or Google account passwords.
